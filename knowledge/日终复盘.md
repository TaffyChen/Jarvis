# 日终复盘（盘面简报五段框架）

盘中或盘后，把「此刻发生了什么、资金在干嘛、接下来盯什么」写成一页简报。  
**框架永久有效；某一版的结论会过期。** 入库检索时优先用本文结构，不要把过期叙事当仍有效的行情事实。

与其他模块：
- 纪律执行：五灯 / 情绪退潮 / 铁律 / 日记 → `五灯仓位.md` `持仓预警.md`
- 个股量价阶段：`量价与主力行为.md`
- 早盘分时：`开盘三十分钟.md`
- 候选池：`盘后选股与竞价异动.md`（可对照「昨日榜 vs 今日表现」，榜本身不是简报）

产出物：侧栏 **盘面简报**（`market_briefs`：同日多版本追加；每版冻结快照 + 报告 + 批注；可选「当日定稿」标签），或对话里临时按五段回答。  
**不要**把简报写进纪律日记——日记记执行与纪律事件，简报记盘面证据与叙事。  
报告是参谋结论，**不下单**；行动建议仍要过利空门禁与有效仓位。

---

## 报告固定五段

| 段 | 标题 | 要回答的问题 |
|----|------|----------------|
| 0 | 一句话定性 | 今天到底是什么局？（换防 / 普涨 / 退潮 / 脉冲…） |
| 1 | 核心信号 | 量能真假、板块浓度、个股旗手与天量票 |
| 2 | 博弈判断 | 谁在撤、谁在攻；细节是否支撑主线 |
| 3 | 定行动 | 按方向：回避 / 等回调 / 可观察；**禁止裸追涨停** |
| 4 | 验证窗口 | 次日 2～3 个可证伪信号；错一个就要降级叙事 |

文风：先结论后证据；区分「金额大」与「浓度高」；区分「放量」与「共识量」。

---

## 一、核心信号（怎么读数）

### 1. 增量资金：放量是否「有用」

| 观察 | 解读 |
|------|------|
| 成交额显著放大，指数涨幅温和 | 常见 **分歧量**：上砸下接，量增价不飞 |
| 放量 + 指数强势扩散 | 更接近 **共识量** |
| 期指（若有）：品种间多空加减仓不一致 | 大票博弈 vs 小票空头先撤等，作辅助，勿单独定性 |

口诀：**放量不涨价 → 别把震荡当单边。**

### 2. 板块轮动：看净流入率，不只看净流入额

- **净流入额**大：可能只是板块体量大（如电子）  
- **净流入率**高：资金浓度更高，更像「真狠角色」  
- **流出端**：防御 / 消费白马被抽血 + 科技或周期吸金 → 警惕**风格切换**，不是普涨

行动含义：跟着**浓度**走，不跟着「排行榜第一的绝对金额」追。

### 3. 个股共振：旗手 + 天量票

- 净流入前列是否**多条线各有旗手**（算力 / 有色 / 通信…）→ 单主线还是扩散  
- 同主题龙头是否**集体净流出** → 老主线可能进入派发 / 换庄  
- **天量不天价**（巨量 + 大跌或滞涨）：短期偏空博弈、中期看筹码交换；至少宣告「躺赢段」结束（对照 `量价与主力行为.md` 出货 / 换手）

---

## 二、博弈判断（叙事怎么立）

用「有组织的撤退 × 有预谋的进攻」检验，但必须落到可核对细节：

1. **撤退侧**：哪条老主线、是否天量换手、龙头是否共振流出  
2. **进攻侧**：新方向是硬催化（国产替代、战略金属禁令等）还是纯概念  
3. **对冲痕迹**：黄金 / 防御是否异动放量 → 机构是否两头下注（共识没看起来那么牢）  
4. **主线阶段**：龙头滞涨后挖上游材料 / 补涨 → 常是中段特征，不是随便说「主升第一天」

细节站不住，就降级为「脉冲」，不要写成「反转」。

---

## 三、定行动（给自己下指令）

按方向写清楚，避免「又想追又想抄」：

| 类型 | 默认姿态 |
|------|----------|
| 天量下跌 / 主题龙头共振流出 | 短期回避，等筹码沉淀 |
| 新主线已连涨 | 方向可认，**等回调**再评估上车，不追连板 |
| 净流入率最高 + 催化硬 | 观察优先级提高，仍过门禁与仓位 |
| 被抽血的消费白马等 | 抽血阶段不抄 |

全局仓位仍服从：**有效仓位 = min(五灯, 情绪退潮)**；复盘叙事再漂亮也不能突破铁律。

---

## 四、验证窗口（次日证伪）

每天复盘结尾固定 2～3 条，格式：

> 若 **A** 失败 → 今日叙事降级为脉冲 / 假换防；  
> 若 **B** 失败 → …；  
> 风险一句话：…

示例维度（按当日改具体标的，勿照抄过期例子）：
- 天量分歧龙头能否止跌  
- 核心吸金板块净流入能否维持量级（如电子是否仍百亿级）  
- 最高净流入率板块浓度是否还在

## 五、系统生成报告时建议采集的字段

页面入口：侧栏 **盘面简报**（左：按日；中上：同日版本时间线；右：当前版正文 + 批注）。

产品形态：交易日为容器，**每次生成追加一版**（不覆盖）；批注挂在具体版本；收盘可点「标为定稿」（仅标签）。便于盘中多次参谋、事后对照「当时依据哪一版下的单」。

| API | 作用 |
|-----|------|
| `GET /api/jarvis/review/snapshot` | 预览**当前**盘面（不落库） |
| `GET /api/jarvis/review/days` | 按日列表 |
| `GET /api/jarvis/review/days/{date}` | 某日版本清单 |
| `GET /api/jarvis/review/versions/{id}` | 某版详情 |
| `POST /api/jarvis/review/generate` | 追加新版：`refreshSnapshot` 重采；或 `baseVersionId` 用旧版快照+批注再生成 |
| `POST /api/jarvis/review/versions/{id}/comments` | 本版批注 |
| `POST /api/jarvis/review/versions/{id}/final` | 标为当日定稿 |

| 区块 | 数据来源（现有能力） |
|------|----------------------|
| 指数涨跌、全市场涨跌家数 | quotes / 广度 |
| 有效仓位、五灯、情绪退潮 | 服务端复算进快照 |
| 持仓盈亏、当日日记摘要 | positions + journal |
| 板块净流入额 / strength | `sector_flow` |
| 自选强弱、破 20 日线 | quotes + klines |
| 纪律条文 | 本文 + 五灯 / 量价 / 开盘三十分钟 |

生成顺序：冻结快照（硬数据）→ 五段叙事 → 验证窗口；基于旧版再生成时吸收该版批注与近期摘要，并**另存新版**。  
缺期指、个股主力净流入明细时：写「数据不足」，**禁止编造精确亿元数字**。

## 范文结构参考（2026-08-05，已过期）

仅作文风与结构样例，**不是当前行情结论**：

- 一句话：科技放量换防，光模块天量分歧  
- 信号：2.66 万亿级放量但指数仅中等涨幅 → 分歧量；电子净流入额高但净流入率不如小金属 / 有色；光模块龙头天量下跌、设备与小金属接棒  
- 行动：光模块短期回避；设备材料等回调；小金属看浓度；消费白马不抄  
- 验证：龙头止跌否、电子净流入量级、小金属浓度  

引用该日细节时必须带日期，并声明可能已失效。

## Jarvis 回答要点

- 用户说「帮我复盘 / 盘面简报」：按五段输出；优先引导打开「盘面简报」页落库，或对话内临时五段  
- 用户贴某日长文：提炼进框架知识或写入对应版本批注，不要把过期个股结论写成永久知识  
- 与持仓冲突时：先报铁律与有效仓位，再谈主题故事  
- 结尾必有验证窗口 + 风险句；附「不构成投资建议」  
- 简报 ≠ 纪律日记：执行记录仍走日记页；同日多版不覆盖，定稿只是标签
