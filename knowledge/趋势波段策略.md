# 趋势波段策略

从「养家情绪周期 + 野人资金量价 + 经典趋势跟随」抽象的 **L1 候选短名单** 口径。  
**不是**自动买卖指令；真正「可买入」仍走评分与利空门禁（L2）。

灵感来源仅作骨架参考（实战派框架，非学术回测圣杯）：情绪周期看赚钱/恐慌效应；选股看资金联动与量价；个股纪律用均线趋势。

## 三层分工

| 层 | 名称 | 回答什么 | 产出 |
|----|------|----------|------|
| L0 | 环境 | 今天能不能做趋势波段 | 阶段标签；退潮/仓位归零则禁止推荐 |
| L1 | 趋势候选 | 哪些票趋势结构还干净 | `趋势波段 TOP5` 短名单 |
| L2 | 可买入 | 能不能按纪律买 | 综合分≥60 **且** 利空复核有效 |

关系：

```
L0 环境允许 → L1 出短名单 → 加入自选 → L2 门禁后才标「可买入」
```

L1 进榜 **≠** L2 可买。当日大涨追高票可以进观察池，仍可能是「观察/不追」。

## L0 环境（与现有模块对齐）

优先复用，不另起炉灶：

- 情绪退潮 / 五灯有效仓位：`五灯仓位.md`、`持仓预警.md`
- 主升确认：`主升第一天.md`
- 盘面温度：涨停生态、昨涨停溢价、破板率（行情条 / 日终复盘）

简易阶段（系统提示用）：

| 阶段 | 粗判 | L1 行为 |
|------|------|---------|
| 退潮 | 情绪退潮或有效仓位=0 | 只展示、标注「不宜新开」 |
| 谨慎 | 五灯风险偏高 | 短名单降权提示 |
| 可做趋势 | 未退潮且有效仓位>0 | 正常出 TOP5 |
| 偏热 | 涨停拥挤、溢价高、破板升 | 仍可出榜，但文案强调不追高潮 |

## L1 硬过滤（必须同时满足）

1. 现价 **≥ MA20**（站上 20 日线）
2. 近 20 日涨幅 **> 0%** 且 **≤ 60%**（有趋势、但避免末端疯狂延伸）
3. PE(TTM)：按板块估值族硬顶（科技 300 / 消费 200 / 周期·金融 80 / 公用 100 / 通用 150 等，见 `评分与分类.md`）
4. 有有效现价与 K 线样本

## L1 趋势分（0–100，用于 TOP5 排序）

| 维度 | 满分 | 偏好 |
|------|------|------|
| 相对 MA20 距离 | 25 | 刚站上或偏离不大（约 0%~8% 最佳） |
| 20 日动量 | 25 | 约 5%~35% 趋势走强；过大扣分 |
| 量比结构 | 20 | **温和放量**优先（约 1.05~2.0 且当日涨幅不过热） |
| 当日涨幅 | 15 | 0%~5% 优于大涨追高；≥7% 明显降权 |
| PE 软分 | 15 | 按估值族分档，非一刀切 |

标签示例（展示用，不单独打分）：`站上20日线` `趋势走强` `温和放量` `当日涨幅偏大` `偏离偏大`。

板块资金若可得：强度靠前可作为 **加分信号文案**，暂不强制改排序核（避免东财板块名与自选板块映射不稳时污染排序）。

## L2 门禁（v4.1）

见 `评分与分类.md`、`三原则两防线.md`：

- 综合分 ≥ 60
- 利空复核有效（≤14 天）
- 偏离门禁：现价 ≤ MA20×1.05
- 五灯 ≤ 2 红；有效仓位 = min(五灯, 情绪退潮)；退潮只卖不买

## 卖出

**不**引入「永不止损」。卖出继续用铁律（v4.1）：

- 铁律 1：缓冲带 + 连续 3/5 日破 MA20×0.98；或同时破 20/60
- 盈利回撤、浮盈翻绿、高位巨量长阴
- 板块分级成本/跟踪止损 + 时间止损（7 日浮盈&lt;0）
- 三级止盈 10% / 20% / 30%

见 `三原则两防线.md`、`持仓预警.md`。

## 与「盘后选股 TOP10」区别

| | 综合 TOP10 | 趋势波段 TOP5 |
|--|------------|----------------|
| 目标 | 估值+趋势+量能的通用候选 | 更干净的趋势结构短名单 |
| 排序 | 综合分 0–100 | 趋势分 0–100 |
| 硬条件 | PE 按估值族硬顶 | **必须站上 MA20** + 20 日动量区间 |
| 追高 | 初筛已抑制大涨 | 当日涨幅≥7% 明显降权 |

二者都是候选；加入自选后仍要过 L2。
