# 五灯仓位

五灯用于**全市场风险预算 → 总仓位上限**，与个股买卖铁律并行。  
口径一律看**全市场**（指数 / 海外 / 涨停生态 / 日历），**不用自选或持仓样本**。  
持仓破线、自选拥挤等账户问题，走持仓预警与个股铁律，不进五灯。

> 版本：v4.1（与 `三原则两防线.md` 对齐）

## 设计原则

1. **全市场分级**：避免自选偏差绑架总仓。
2. **硬灯 / 软灯分离**：软灯单独点亮不能把仓位打到归零。
3. **与情绪模块分工**：情绪描述「热不热」；五灯回答「总仓还能开多大」。
4. **与情绪退潮并行**：有效上限 = min(五灯上限, 情绪退潮上限)。

## 五盏灯

### 1. 指数破位（硬）
- 样本：沪深 300 `sh000300`、创业板指 `sz399006`（上证作展示参考，不单独点灯）
- 红灯（满足其一）：
  - 沪深 300 **连续 3 个交易日**收盘跌破 **MA60**
  - **或** 创业板指连续 3 个交易日收盘跌破 MA60
- 含义：大盘中期趋势转弱，总仓应先降

### 2. 海外冲击（硬）
- 红灯（满足其一）：
  - 标普 500 日跌幅 **≤ -1.5%**
  - 纳指（优先 `sz159659`，否则纳指指数）日跌幅 **≤ -2.0%**
- 含义：隔夜风险偏好显著恶化

### 3. 生态恶化（硬）
- 数据：全市场涨停池衍生
- 红灯（满足其一即可）：
  - 昨涨停今日亏损（涨跌幅 &lt; 0）**≥ 3** 只
  - 跌停家数 **≥ 10**
  - 涨停样本 **≥ 20** 且最高连板高度在 **1～2**（`maxDays=0` 视为样本不足，不点灯）
- 含义：短线赚钱效应变差，接力容错下降

### 4. 业绩窗口（软）
- **1 月 17 日–1 月 31 日**、**7 月 1 日–7 月 15 日**
- 含义：财报披露高峰，波动与雷暴抬升

### 5. 杠杆退潮（软 · 手动）
- 用户确认两融余额连续约 5 日下降后点亮
- 缺自动数据源，故为软灯；单独点亮不能归零

## 红灯数 → 仓位上限

| 红灯数 | 最大仓位 | 含义 |
|--------|----------|------|
| 0 红 | 80% | 正常操作 |
| 1 红 | 50% | 谨慎，新仓需更强理由 |
| 2 红 | 30% | 防守，只减不加 |
| 3 红 | 10% | 极度防守，仅保留核心仓 |
| ≥ 4 红 | **0%** | 空仓，只卖不买 |

附加规则：
- **软灯地板**：硬灯 = 0 且仅软灯点亮时，上限 **≤ 30%**（不到 0）。
- **硬灯加速**：硬灯 ≥ 2 个亮红 → 直接进入 ≤ 10% 档。
- 「满仓」定义为最大允许 **80%**，永远不满 100%。

## 与情绪退潮叠加

情绪退潮（上涨占比 &lt; 40% **或** 上涨家数 &lt; 1500）→ 只卖不买、仓位 ≤ 3 成。  
**有效仓位上限 = min(五灯上限, 情绪退潮上限)**。

## 与「市场情绪 / 今日建议」分工

| 模块 | 回答的问题 |
|------|------------|
| 市场情绪 | 盘面热不热、溢价/晋级/回撤细节 |
| 五灯 | 全市场风险预算 → 总仓上限 |
| 今日建议 | 仓位 / 风格 / 主线 / 自选重合；重合≠买入 |

持仓是否破线、自选是否拥挤：**不进五灯**，进预警与铁律。

## Jarvis 回答要点
- 先报红灯数与有效仓位，再点名硬/软灯
- 勿把五灯说成选股理由
- 杠杆灯未手动点亮时不要臆造
- 与情绪退潮并存时只给一个最终上限
- ≥ 4 红时不得建议任何买入
