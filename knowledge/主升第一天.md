# 主升第一天

用于判断「情绪冰点后、主升浪第一天」是否可考虑进攻。  
**满仓进攻只应发生在主升确认日附近**；未确认时不追高。

## 六项检查

### 1. 昨日冰点已确认（手动）
- 手动开关：用户确认昨日为冰点
- 冰点参考：昨日上涨家数 **&lt; 1500**，或涨停负溢价/无溢价
- 未手动确认 = 未满足

### 2. 全市场赚钱效应扩散
- 条件：全市场上涨家数占比 **&gt; 60%**
- 数据优先用全市场广度；缺失则未知

### 3. 量能放大
- 理想：沪深指数量能较昨日 **≥ +10%**（量比 ≥ 1.1）
- 回退：指数 K 线缺失时，用自选放量占比 **&gt; 50%** 近似
- 两者皆无 = 未知

### 4. 科技主线明确
- 样本：自选中板块含 半导体 / CPO / PCB / AI / 算力 的个股
- 条件：科技样本翻红占比 **&gt; 70%**
- 无样本 = 未知

### 5. 涨停梯队健康
- 同时满足：
  - 涨停家数 **≥ 50**
  - 炸板率 **&lt; 30%**（炸板 / (涨停+炸板)）
  - 最高连板天数 **≥ 2**
- 涨停池数据缺失 = 未知

### 6. 亏钱效应收敛
- 同时满足：
  - 有涨停数据（zt &gt; 0）
  - 跌停家数 **≤ 20**
  - 跌停家数 **&lt; 涨停家数的一半**

## 裁决规则

设 met = 满足项数，unknown = 未知项数，total = 6。

| 条件 | 结论 |
|------|------|
| unknown ≥ 2 且 met &lt; 3 | 数据不足，先人工核对 |
| met == 6 | **确认**主升第一天；尾盘 14:30 后条件保持可考虑进攻 |
| met ≥ 4 且已过 14:30 | **疑似确认**，尾盘保持即确认 |
| met ≥ 4 且未到 14:30 | **疑似**，14:30 后再确认 |
| 其他 | **未确认**，不追高 |

## Jarvis 回答要点
- 主升确认 ≠ 随便买；仍要过个股利空门禁与五灯仓位
- 涨停池/指数 K 缺失时主动说明「未知」，不要当满足
- 提醒用户：冰点开关需自己点，系统无法自动认定昨日冰点
