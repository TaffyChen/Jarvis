# 情绪周期与量价假说（展示口径）

两套**展示用**阶段标签，辅助读盘；**不是**买卖指令。  
冲突时铁律 / 五灯 / 利空门禁优先（见 `三原则两防线.md`）。

## 一、全市场情绪六段（养家骨架）

位置：盘面页「市场情绪」；自选顶栏决策胶囊可附短标签。

| 阶段 | 粗判信号（系统启发式） | 仓位含义 |
|------|------------------------|----------|
| 冰点 | 手动确认昨日冰点，或广度极弱+涨停生态冷 | 空仓/极轻，等回暖 |
| 回暖 | 退潮解除后的修复：上涨回升、首板增多 | 轻仓试错 |
| 发酵 | 赚钱效应扩散：涨停与连板高度抬升、破板可控 | 可按主线控节奏 |
| 高潮 | 拥挤：高连板+涨停多+情绪温度偏热 | 控仓忌追 |
| 分歧 | 破板升、昨涨停溢价转负，高度仍在 | 减仓防回撤 |
| 退潮 | 情绪退潮规则触发（上涨&lt;1500 或占比&lt;40%） | 只卖不买 |

说明：
- 「冰点」自动侧仅作参考，**进攻仍依赖手动冰点开关**（`主升第一天.md`）
- 六段是当日定性，与温度计、折线并列，不替代有效仓位数字

### 情绪温度折线（盘面）

- 温度 0–100：广度 + 涨停生态 − 破板/回撤 − 五灯风险 − 退潮（前后端同口径）
- **冰点带 ≤35**、**沸点线 ≥78**（对齐偏热/亢奋阈值）；温度旁标注阶段与相对位置（冰点区/一般/偏暖/过热区）
- **市场高度**：按交易日沉淀「最高板」，与温度并列展示（样本随开市日积累；周末不采样）
- 近一月约 22 个交易日点；历史=当日收盘点，末点=今日实时

## 二、个股量价假说（野人四阶段骨架）

位置：自选/持仓卡片；文案必须带「假说」或置信度。

对齐 `量价与主力行为.md`：

| 假说 | 相对可判 | 展示要求 |
|------|----------|----------|
| 出货 | 高（高位巨量长阴等） | 可标「偏出货」 |
| 拉升 | 中 | 「偏拉升（中置信）」 |
| 洗盘 | 中低 | 「偏洗盘（低置信）」 |
| 建仓/吸筹 | 最低 | 「偏吸筹（低置信）」；禁止当买入依据 |
| 不明 | 数据不足 | 不展示或「量价不明」 |

禁止：把「偏吸筹」写成「主力建仓完成，建议买入」。

## 三、与操作建议的关系

操作建议继续输出：仓位 / 风格 / 主线 / 自选重合。  
情绪六段作为**环境输入**写入建议备注或指标行，不另起黑箱打分替代纪律。
重合判定对照资金强度 Top8；展示主线为 Top3；**重合 ≠ 买入指令**。
