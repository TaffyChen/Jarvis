# 三原则两防线 · 交易纪律

## 灵魂三问
1. 买前问：股价在20日线上吗？量能放大了吗？
2. 持仓问：如果现在空仓，还会买它吗？（不会就卖）
3. 止盈问：今天最高价回撤到止损线了吗？

## 五条铁律
1. 趋势破线减半仓，再破均线全走光。跌破20日线先卖一半，次日站不回或破60日线清仓。
2. 盈利回撤三五个，最高点下必离场。浮盈超10%后从最高点回撤3%~5%，清掉剩余仓位。
3. 浮盈翻绿马上卖，绝不让利变亏损。浮盈曾超3%，回落至成本附近且从高点回撤≥1.5%时保本出局。
4. 情绪退潮只卖不买。上涨家数<1500或占比<40%，仓位≤3成。
5. 高位巨量长阴线，闭眼清仓。60日涨超50%+量≥5日均量2倍+跌≥5%。

## 买入门禁
- 综合评分 ≥ 60 **且** 利空复核有效（riskOk=true，复核未过期≤14天）才可「可买入」。
- 仅技术分达标不够；分析过期或利空未过，最高只能「观察」。

## 五灯仓位
1. 换手拥挤（自选平均换手>10%）
2. 杠杆5连降（手动）
3. 业绩验证期（1/17-1/31、7/1-7/15）
4. 海外隔夜大跌：标普日跌≤-1.5% 或 纳指ETF日跌≤-2%
5. 持仓过半破20日线

仓位：0红8成 / 1红5成 / 2红3成 / 3红1成 / 4-5红归零。
