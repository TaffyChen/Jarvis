## 〇、规则优先级（冲突时谁说了算）

多条规则同时触发时，**高优先级覆盖低优先级**，同一标的同一时间只执行最高优先级的卖出指令。

| 优先级 | 规则 | 动作 |
|--------|------|------|
| **P0** | 五灯 ≥ 4 红 | 全部清仓，只卖不买 |
| **P0** | 铁律 5：高位巨量长阴 | 清仓 |
| **P0** | 硬止损：成本亏损 ≥ 8%（主板）/ 12%（创业板·科创板）/ 5%（ST） | 立即卖出 |
| **P0** | 时间止损：持仓 7 日浮盈 &lt; 0 → 无条件退出 | 市价卖出 |
| **P1** | 铁律 1：连续 3 日收盘 &lt; MA20×0.98 / 破 60 日线 | 减半仓 → 清仓 |
| **P1** | 铁律 2：浮盈超 10% 后从高点回撤 ≥ 3%（强趋势 3.6%） | 清掉剩余仓位 |
| **P1** | 铁律 3 扩展：曾有盈利现已亏损 | 立即卖出 |
| **P2** | 铁律 3：浮盈翻绿回到成本附近（双确认） | 保本出局 |
| **P2** | 止盈：浮盈 ≥ 10% / 20% / 30% | 分批卖出（三级止盈） |
| **P3** | 委比恶化 / 今日大跌 | 关注 / 警告 |

> **P0 是无条件执行线**——不管什么理由，先走再说。P1 是趋势与利润保护线。P2 是止盈与保本线。P3 只是提醒。

## 一、灵魂三问

三问不是「想一想」，是**硬门禁**——任何一个答「否」，对应动作立即执行。

| 问 | 条件 | 不满足则 |
|----|------|----------|
| **买前问** | 股价在 20 日线上方 **且** 偏离 ≤ 5% **且** 当日量比 &gt; 1.0 | 不买 |
| **持仓问** | 若此刻空仓，仍会买入该标的 | 不会 → 卖 |
| **止盈问** | 今日最高价未回撤至止损线（从买入后最高点回撤 &lt; 板块止损阈值） | 已回撤 → 执行止损 |

> 止损阈值按板块分级：主板 8%、创业板/科创板 12%、ST 5%。强趋势中（MA20 向上 + 20 日涨幅 &gt; 10%）阈值 × 1.2 放宽。

## 二、五条铁律

### 铁律 1：趋势破线

| 条件 | 动作 |
|------|------|
| 收盘 &lt; MA20 但 ≥ MA20×0.98（2% 缓冲带内） | **观察**，不计入破线天数 |
| 连续 3 日收盘 &lt; MA20×0.98 | **减半仓**，次日开盘执行 |
| 连续 5 日收盘 &lt; MA20×0.98 | **清仓** |
| 同时跌破 20 日线 + 60 日线 | **清仓**，无需等确认 |

> **[v4.1 回测优化]** 缓冲带 + 确认期延长（3/5 日）+ 「站回」仅认收盘 ≥ MA20。

### 铁律 2：盈利回撤

| 条件 | 动作 |
|------|------|
| 浮盈曾超 10%，从买入后最高点回撤 ≥ 3%（强趋势 3.6%） | 清掉剩余仓位 |

- 「买入后最高点」= 买入日之后的最高价（含盘中高点）。
- 与止盈线配合：先在 10% 卖一部分锁定利润，剩余仓位如从最高点回撤 3%，清掉。
- 强趋势（MA20 向上 + 20 日涨幅 &gt; 10%）时回撤阈值放宽至 3.6%。

### 铁律 3：浮盈翻绿

| 条件 | 动作 |
|------|------|
| 浮盈曾超 3%，现回落至成本 ±0.5% **且** 从高点回撤 ≥ 1.5% | 保本出局 |
| 浮盈曾超 3%，现已亏损（pnl &lt; 0）**且** 从高点回撤 ≥ 1.5% 或破 20 日线 | 立即卖出 |

- **双确认**避免盘中噪音。**核心：绝不让任何一笔盈利单最终亏损离场。**

### 铁律 4：情绪退潮

| 条件 | 动作 |
|------|------|
| 上涨家数 &lt; 1500 **或** 上涨占比 &lt; 40% | 只卖不买，仓位 ≤ 3 成 |
| 主升第一天确认（六项检查通过） | 可放宽至 80%（仍不满仓） |

- 与五灯并存时 **取更严**：有效上限 = min(五灯上限, 3 成)。
- 主升认定见 `主升第一天.md`，当日情绪条件见 `市场情绪四条件.md`。

### 铁律 5：高位巨量长阴

同时满足以下三项 → **清仓**：

| 条件 | 阈值 |
|------|------|
| 60 日涨幅 | &gt; 50% |
| 当日成交量 | ≥ 5 日均量的 2 倍 |
| 当日跌幅 | ≥ 5% |

- 尾盘确认后执行（14:50 后），避免盘中误判。

## 三、买入门禁

### 3.1 三重门禁（缺一不可）

| 门禁 | 条件 | 不满足则 |
|------|------|----------|
| 评分门禁 | 综合评分 ≥ 60（满分 100） | 最高评级「观察」 |
| 利空门禁 | 利空复核有效（riskOk=true，复核未过期 ≤ 14 天） | 最高评级「观察」 |
| 偏离门禁 | 收盘价 ≤ MA20 × 1.05（偏离均线不超过 5%） | 最高评级「不追」 |

另：**五灯 ≤ 2 红** 才可升级为「可买入」；否则最高「观察」。

> 趋势波段 / 趋势回踩 / 资金共振 / 综合质量短名单都是 **观察候选**，不等于可买入。见对应策略文档与 `评分与分类.md`。

### 3.2 评分构成（满分 100）

见 `评分与分类.md`（PE / 趋势位置 / 20 日动量 / 量价 / 委比）。

### 3.3 利空复核清单

以下任意一项命中即 riskOk=false：

- 大基金 / 国家队减持公告（近 30 天内）
- 控股股东或 5% 以上股东减持（近 30 天内，排除已届满的）
- 业绩暴雷：季报净利润同比 &lt; -30% 或由盈转亏
- 财务异常：被 ST / *ST、被立案调查、年报非标
- 监管处罚：证监会处罚、交易所公开谴责（近 90 天内）
- 限售股解禁：近 14 天内或未来 14 天内有大规模解禁（&gt; 流通盘 5%）

复核有效期 **14 天**，过期需重新确认。

### 3.4 评级与分类

| 评级 | 条件 | 动作 |
|------|------|------|
| **可买入** | 评分 ≥ 60 **且** 利空复核通过 **且** 偏离 ≤ 5% **且** 五灯 ≤ 2 红 | 可以买入 |
| **观察** | 评分 ≥ 60 但利空未过 / 五灯 3 红 / 分析过期 | 等信号，不急 |
| **不追** | 技术面达标但偏离 &gt; 5% / 左侧反弹 / 追高风险高 | 等回踩，不追高 |
| **持仓** | 当前实际持有的标的 | 按持仓预警管理 |
| **排除** | 有利空 / PE 过高 / 评分 &lt; 30 | 不碰 |

## 四、止损止盈体系

### 4.1 止损线（三轨制 + 时间止损，先触发先执行）

| 轨道 | 定义 | 主板 | 创业板/科创板 | ST | 用途 |
|------|------|------|-------------|------|------|
| 成本止损 | 从买入价算 | 亏损 ≥ 8% | 亏损 ≥ 12% | 亏损 ≥ 5% | 保护本金 |
| 跟踪止损 | 从买入后最高点算 | 回撤 ≥ 8% | 回撤 ≥ 10% | 回撤 ≥ 5% | 保护利润 |
| 时间止损 | 从买入日算 | 7 日浮盈 &lt; 0 | 同左 | 同左 | 过滤烂入场 |

强趋势（MA20 向上 **且** 20 日涨幅 &gt; 10%）时，止损与铁律 2 回撤阈值放宽 **20%**。

### 4.2 止盈线（三级止盈）

| 条件 | 动作 |
|------|------|
| 浮盈 ≥ 10% | 卖出 **1/3 到 1/2** 仓位 + 转出利润到银行账户 |
| 浮盈 ≥ 20% | 再卖出 1/3，保留 1/3 底仓用跟踪止损保护 |
| 浮盈 ≥ 30% | 清仓或保留 1/4 底仓，设保本止损线（不低于买入价） |

### 4.3 归零拷问

每日对每只持仓问一次：「如果现在空仓，还会买它吗？」

- 「不会」→ 卖出；「不确定」→ 减半仓；「会」→ 继续持有
- 系统在**持仓盈利但跌破 20 日线**时自动触发此提醒

## 五、五灯仓位（摘要 · 全市场）

详见 `五灯仓位.md`。红灯数 → 上限：0→80% / 1→50% / 2→30% / 3→10% / ≥4→0%。软灯单独不能归零；硬灯 ≥ 2 → 直接进入 ≤10% 档。

## 六、仓位分级入场

| 信号强度 | 条件 | 首仓比例 | 加仓条件 |
|---------|------|---------|---------|
| **强信号** | 评分 ≥ 75 + 五灯 0 红 + 主升确认 | 40% | 浮盈 5% 后加至 60% |
| **正常信号** | 评分 ≥ 60 + 五灯 ≤ 2 红 | 25% | 浮盈 3% 后加至 40% |
| **弱信号** | 评分 60–70 + 五灯 2 红 | 15% | 不加仓，走就走 |

- 单票最大仓位 **40%**（含加仓后），除非主升确认且评分 ≥ 75。
- 加仓必须在**盈利状态下**进行——亏损不加仓。

## 七、风险硬约束

### 7.1 集中度

| 约束 | 阈值 | 触发动作 |
|------|------|----------|
| 单票成本占比 | ≥ 40% | 警告：集中度偏高 |
| 单板块成本占比 | ≥ 60% | 警告：同板块暴露过高 |
| 单票成本占比 | ≥ 60% | 危险：强制减仓至 &lt; 40% |
| 持仓标的数 | &lt; 3 | 警告：分散不足 |

### 7.2 涨跌停板特殊处理

| 情况 | 动作 |
|------|------|
| 持仓跌停 | 挂单排队，不计入「未执行」 |
| 持仓涨停 | 不卖（除非铁律 5 触发） |
| 开盘即跌停（一字板） | 次日集合竞价挂跌停价卖出 |

### 7.3 缺口风险

| 情况 | 预防措施 |
|------|----------|
| 业绩窗口期（1/17–1/31、7/1–7/15）| 高位股减仓至 ≤ 5% 仓位 |
| 重大事件前 | 前一日收盘前减仓至 ≤ 3 成 |
| 隔夜海外大跌（标普跌 ≥ 1.5%）| 次日开盘不计成本减仓至五灯允许上限 |

### 7.4 组合回撤控制

| 回撤幅度 | 动作 |
|---------|------|
| 组合从净值高点回撤 ≥ 5% | 暂停新建仓，仅保留已有持仓 |
| 组合从净值高点回撤 ≥ 8% | 全部持仓减半，重新评估每只标的 |
| 组合从净值高点回撤 ≥ 12% | 清仓至 ≤ 2 成，退出观察一周 |

## 八、再入场冷却

| 卖出类型 | 冷却期 | 说明 |
|---------|--------|------|
| 止损卖出（铁律 1 / 硬止损） | 5 个交易日 | 同一标的不再买入 |
| 止盈卖出（三级止盈） | 3 个交易日 | 可买回但需重新通过三重门禁 |
| 铁律 5 清仓 | 10 个交易日 | 该标的短期不再碰 |
| 五灯 ≥ 4 红全清 | 至五灯降至 ≤ 2 红 | 不按时间，按信号 |

## 十、Jarvis 纪律

1. 系统建议必须服从铁律与门禁，**不得劝用户抗单、加仓摊薄成本、或越线持有**。
2. 修改策略必须通过 `strategy_patch` + 用户 HITL 确认。
3. 所有预警必须附带**具体数据**（价格、百分比、日期），禁止模糊表述。
4. 系统不得在五灯 ≥ 4 红时建议任何买入操作。
5. 系统不得在情绪退潮期建议加仓。

## 附录：关键定义

| 术语 | 精确定义 |
|------|----------|
| 20 日线（MA20） | 最近 20 个交易日收盘价的简单移动平均 |
| 60 日线（MA60） | 最近 60 个交易日收盘价的简单移动平均 |
| 买入后最高点 | 从买入日（含）到当前时刻的最高价（含盘中高点） |
| 站回 20 日线 | **收盘价** ≥ MA20，盘中触及不算 |
| 浮盈 | (当前价 - 买入价) / 买入价 × 100% |
| 从高点回撤 | (当前价 - 买入后最高点) / 买入后最高点 × 100% |
| 量比 | 当日成交量 / 过去 5 日平均成交量 |
| 委比 | (买盘委托量 - 卖盘委托量) / 总委托量 × 100% |
| 强趋势 | MA20 方向向上 **且** 20 日涨幅 &gt; 10% |
| 满仓 | **80%**（本文档中永远不满 100%） |
| 主升第一天 | 需通过 `主升第一天.md` 中的六项检查 |
| 情绪退潮 | 全市场上涨家数 &lt; 1500 或上涨占比 &lt; 40% |
