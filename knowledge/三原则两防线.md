# 三原则两防线 · 交易纪律

总纲文档。细则阈值见：`评分与分类.md`、`五灯仓位.md`、`持仓预警.md`、`主升第一天.md`。

## 灵魂三问
1. **买前问**：股价在 20 日线上吗？量能放大了吗？
2. **持仓问**：如果现在空仓，还会买它吗？（不会就卖）
3. **止盈问**：今天最高价回撤到止损线了吗？

## 五条铁律
1. **趋势破线**：跌破 20 日线先卖一半；次日站不回或破 60 日线清仓。
2. **盈利回撤**：浮盈曾超 10% 后，从买入后最高点回撤 3%~5%，清掉剩余。
3. **浮盈翻绿**：浮盈曾超 3%，回落至成本附近且从高点回撤 ≥ 1.5% → 保本出局；已翻绿亏损则立即卖。
4. **情绪退潮**：上涨家数 &lt; 1500 或上涨占比 &lt; 40% → 只卖不买，仓位 ≤ 3 成。满仓只在主升确认附近考虑。与五灯并存时 **取更严**（有效上限 = min(五灯, 3 成)）。
5. **高位巨量长阴**：60 日涨超 50% + 量 ≥ 5 日均量 2 倍 + 当日跌 ≥ 5% → 清仓。

辅助硬阈值（系统已实现）：
- 止损线 **-8%**（相对成本或相对买入后高点回撤）
- 浮盈 **≥ 10%** 提醒强制兑现部分

## 买入门禁
- 综合评分 ≥ 60 **且** 利空复核有效（riskOk=true，复核未过期 ≤ 14 天）才可「可买入」
- 仅技术分达标不够；分析过期或利空未过，最高只能「观察」
- 详见 `评分与分类.md`

## 五灯仓位（摘要）
1. 换手拥挤（自选平均换手 &gt; 10%）
2. 杠杆 5 连降（手动）
3. 业绩验证期（1/17–1/31、7/1–7/15）
4. 海外隔夜大跌：标普 ≤ -1.5% 或 纳指 ETF ≤ -2%
5. 持仓过半破 20 日线

仓位：0 红 8 成 / 1 红 5 成 / 2 红 3 成 / 3 红 1 成 / 4–5 红归零。  
详见 `五灯仓位.md`。
